# Retail Sales & Business Performance Analysis Dashboard

This project focuses on analyzing retail sales data using Microsoft Excel to understand business performance, sales trends, profitability, and customer purchasing behavior.

The project uses Excel's data analysis capabilities, including Pivot Tables, Pivot Charts, and interactive visualizations, to transform raw sales data into meaningful business insights.

### Key Analysis Areas
- **Sales Analysis:** Monthly sales trends, regional sales performance, and category-wise sales.
- **Profit Analysis:** Profitability across different regions, months, and shipping modes.
- **Quantity Analysis:** Product sub-category, regional, and payment-mode-wise quantity analysis.
- **Customer Analysis:** Customer purchasing patterns and top 10 customer analysis.
- **Product Analysis:** Top 10 products based on sales performance.
- **Shipping Analysis:** Sales, quantity, and profit analysis across different shipping modes.

### Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Interactive Dashboards

### Project Objective
To convert raw retail sales data into meaningful visual insights that help understand business performance, identify sales patterns, evaluate profitability, and support data-driven decision-making.
